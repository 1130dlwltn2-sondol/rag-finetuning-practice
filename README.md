# RAG와 LLM 파인튜닝 실전

검색으로 지식을 연결하고, 학습으로 모델을 다듬는 방법을 처음부터 끝까지 다룬 실전서입니다.

거대 언어 모델을 업무에 쓰면 두 가지 벽에 부딪힙니다. 모델이 모르는 최신 정보나 사내 문서를 물으면 엉뚱한 답을 내놓는 것, 그리고 우리 일에 맞는 말투와 형식을 끝까지 유지하지 못하는 것입니다. RAG는 외부 지식을 검색해서 답에 붙이는 방법이고, 파인튜닝은 모델 자체를 우리 데이터로 다듬는 방법입니다. 이 책은 두 기술을 나란히 놓고 "언제 무엇을 쓸지"까지 정리합니다.

RAG 파트에서는 임베딩과 벡터 데이터베이스, 청킹 전략, 하이브리드 검색, 리랭킹, 검색 품질 평가를 다룹니다. 파인튜닝 파트에서는 데이터 준비와 전처리, LoRA와 QLoRA, 학습 설정과 하이퍼파라미터, DPO, 평가와 검증, 추론 배포를 다룹니다. 마지막에는 두 기술을 결합한 사내 문서 Q&A 챗봇 실전 프로젝트와 확인 문제 20문항을 수록했습니다.
