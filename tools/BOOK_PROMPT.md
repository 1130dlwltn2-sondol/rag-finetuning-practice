또한 RAG와 파인튜닝과 관련된 최신 공식 자료를 직접 조사하여 참고한다. 대표적으로 사용하는 프레임워크와 모델의 공식 문서(임베딩 모델, 벡터 데이터베이스, 파인튜닝 라이브러리)를 확인하고, 제공된 자료에 없는 내용이라도 학습에 필요하거나 중요하다고 판단되면 최신 공식 자료를 직접 조사하여 추가한다.

책에는 RAG와 파인튜닝 학습에 필요한 내용을 가능한 한 빠짐없이 포함한다. RAG 파트에서는 임베딩과 벡터 데이터베이스, 청킹 전략, 하이브리드 검색(벡터+키워드), 리랭킹, 검색 품질 평가를 다룬다. 파인튜닝 파트에서는 데이터 준비와 전처리, LoRA/QLoRA를 비롯한 효율적 파인튜닝 기법, 학습 설정과 하이퍼파라미터, 평가와 검증, 추론 배포까지 다룬다. 마지막에는 RAG와 파인튜닝을 언제 각각 써야 하는지 비교 기준을 정리한다. 사람들이 관심을 가질 가능성이 높은 주제 1개도 직접 선정하여 별도 챕터 또는 실전 프로젝트 형태로 추가한다.

필요한 설명용 이미지도 제작하여 적절한 위치에 배치한다. 표지용 PNG 이미지도 별도로 제작하며 비율은 100:130으로 한다. 예를 들어 1000x1300 또는 동일 비율의 크기를 사용한다. 표지는 글자가 크고 명확하게 보여야 하며, 현대적이고 전문적인 기술 서적 느낌과 높은 가독성을 갖도록 제작한다. 완성된 표지는 프로젝트 폴더에 저장하고 책의 첫 페이지에도 동일하게 사용한다.
