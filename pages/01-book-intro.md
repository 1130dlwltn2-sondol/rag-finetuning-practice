# 책 소개

이 책은 RAG(검색 증강 생성)와 LLM 파인튜닝을 처음부터 끝까지 다룬 실전서입니다. 거대 언어 모델을 업무에 쓰다 보면 두 가지 벽에 부딪힙니다. 모델이 모르는 최신 정보나 사내 문서를 물으면 엉뚱한 답을 내놓는 것, 그리고 우리 일에 맞는 말투와 형식을 끝까지 유지하지 못하는 것입니다. RAG는 외부 지식을 검색해서 답에 붙이는 방법이고, 파인튜닝은 모델 자체를 우리 데이터로 다듬는 방법입니다. 둘 다 "모델을 내 일에 맞게 쓰는 법"이지만, 쓰는 타이밍과 비용, 효과가 완전히 다릅니다.

많은 입문서가 둘 중 하나만 다룹니다. 하지만 실무에서는 두 기술을 나란히 놓고 판단해야 합니다. 사내 문서를 물어보는 챗봇은 RAG로 충분한 경우가 많고, 특정 형식의 보고서를 매번 같은 품질로 뽑아내야 한다면 파인튜닝이 답이 됩니다. 이 책은 RAG 파트에서 임베딩과 벡터 데이터베이스, 청킹 전략, 하이브리드 검색, 리랭킹, 검색 품질 평가까지 검색 파이프라인 전체를 다룹니다. 파인튜닝 파트에서는 데이터 준비와 전처리, LoRA와 QLoRA의 원리, 학습 설정과 하이퍼파라미터, DPO 같은 선호도 최적화, 평가와 검증, 추론 배포까지 실제 학습을 돌리는 과정을 따라갑니다. 마지막에는 RAG와 파인튜닝을 언제 각각 써야 하는지 비교 기준을 정리했습니다.

책의 구성은 다음과 같습니다. Part 1에서는 RAG가 무엇인지, 임베딩과 벡터 데이터베이스가 어떻게 동작하는지 배우고 첫 RAG 시스템을 직접 만들어 봅니다. LangChain과 LlamaIndex 같은 프레임워크 선택 기준도 함께 다룹니다. Part 2에서는 검색 품질을 끌어올리는 기술을 다룹니다. 청킹 전략, 하이브리드 검색, 리랭킹, 검색 품질 평가로 이어지는 흐름이며, 에이전트가 스스로 검색을 판단하는 에이전틱 RAG도 별도 장으로 준비했습니다. Part 3에서는 LLM 파인튜닝을 다룹니다. 데이터 준비부터 LoRA와 QLoRA의 원리, 학습 설정, DPO, 평가, 배포까지 실제 학습 파이프라인을 따라갑니다. Part 4에서는 RAG와 파인튜닝의 선택 기준을 정리하고, 두 기술을 결합한 사내 문서 Q&A 챗봇 실전 프로젝트로 마무리합니다.

각 장은 개념 설명, 따라 하기 실습, 핵심 정리로 구성됩니다. 실습은 Python 환경을 갖춰 놓고 따라 하면 됩니다. RAG 실습은 CPU에서도 충분히 돌릴 수 있고, 파인튜닝 실습은 16GB급 GPU 1장이나 무료 GPU 환경을 기준으로 설명합니다.

이 책은 본문 18개 장과 실전 프로젝트 1개, 확인 문제 20문항으로 구성되어 있습니다. 다 읽고 나면 "우리 일에는 RAG를 쓸지, 파인튜닝을 할지, 둘을 어떻게 엮을지"를 스스로 판단할 수 있게 됩니다.
