## 70. 확인 문제와 해설

이 장의 문제로 책 전체의 핵심 내용을 점검한다. 객관식과 단답형 20문항이며, 각 문항 뒤에 해설을 붙였다. 먼저 답을 생각해보고 해설을 읽는 것을 권한다.

### 문제

1. RAG에서 LLM이 환각을 일으키는 근본적인 이유로 가장 적절한 것은?
  가. 학습 데이터에 없는 최신 정보를 모델이 지어내어 답하기 때문이다
  나. 벡터 데이터베이스의 저장 용량이 부족하기 때문이다
  다. 프롬프트의 길이가 너무 짧기 때문이다
  라. GPU 메모리가 부족하기 때문이다

2. 코사인 유사도가 1에 가까울수록 두 벡터의 관계는?
  가. 서로 반대 방향을 가리킨다
  나. 의미적으로 유사하다
  다. 길이가 같다
  라. 차원이 다르다

3. 인덱싱과 질의에 서로 다른 임베딩 모델을 사용했을 때 생길 수 있는 문제는?
  가. 검색 속도가 빨라진다
  나. 벡터 공간이 달라져 유사도 계산이 무의미해진다
  다. 저장 용량이 절반으로 줄어든다
  라. 한국어 처리가 자동으로 개선된다

4. 벡터 데이터베이스가 정확한 최근접 이웃 탐색 대신 근사 최근접 이웃(ANN)을 쓰는 이유로 가장 적절한 것은?
  가. 정확도를 높이기 위해서
  나. 대규모 데이터에서 검색 속도를 확보하기 위해서
  다. 저장 용량을 늘리기 위해서
  라. 임베딩 모델을 교체하기 쉽게 하기 위해서

5. 청킹할 때 권장되는 토큰 수와 오버랩 비율은?
  가. 50~100 토큰, 오버랩 없음
  나. 400~512 토큰, 오버랩 10~20퍼센트
  다. 2000~4000 토큰, 오버랩 50퍼센트
  라. 문서 전체를 하나의 청크로 사용

6. 하이브리드 검색에서 RRF(Reciprocal Rank Fusion)의 역할은?
  가. 벡터 검색 결과와 BM25 검색 결과의 순위를 융합하는 것이다
  나. 임베딩 벡터의 차원을 줄이는 것이다
  다. 문서를 자동으로 요약하는 것이다
  라. 검색 쿼리를 확장하는 것이다

7. 리랭킹을 도입하기 전에 먼저 해야 할 일로 가장 적절한 것은?
  가. 무조건 크로스엔코더를 학습시킨다
  나. 정밀도가 병목인지 측정으로 확인한다
  다. 벡터 DB를 교체한다
  라. 청크 크기를 무조건 줄인다

8. RAGAS의 faithfulness가 측정하는 것은?
  가. 답변이 검색된 문맥에 근거하는 정도
  나. 답변의 길이 적절성
  다. 검색 속도
  라. 모델의 파라미터 수

9. 에이전틱 RAG의 특징으로 가장 적절한 것은?
  가. 검색 없이 항상 모델 지식만으로 답한다
  나. 에이전트가 검색 필요 여부를 판단하고 검색-추론 루프를 돈다
  다. 벡터 DB를 사용하지 않는다
  라. 학습을 통해 가중치를 매번 바꾼다

10. 파인튜닝을 고려하기 전에 먼저 시도해야 할 방법으로 옳지 않은 것은?
  가. 프롬프트 개선
  나. RAG 도입
  다. 퓨샷 예제 추가
  라. 바로 전체 파라미터 학습 시작

11. 인스트럭션 데이터에서 데이터 품질이 양보다 중요한 이유로 가장 적절한 것은?
  가. 저품질 데이터는 모델이 잘못된 패턴을 학습하게 만들기 때문이다
  나. 고품질 데이터는 저장 용량을 줄여주기 때문이다
  다. 양이 많으면 학습이 빨라지기 때문이다
  라. 데이터가 적으면 평가가 쉬워지기 때문이다

12. LoRA의 저랭크 분해에서 학습하는 행렬은?
  가. 원래 가중치 행렬 전체
  나. W = W0 + BA 에서의 A와 B (저랭크 행렬)
  다. 임베딩 행렬 전체
  라. 어텐션 마스크

13. QLoRA가 16GB GPU 한 장으로 큰 모델을 학습할 수 있게 하는 핵심 기법은?
  가. 4비트 양자화(NF4)로 가중치 메모리 사용량을 줄이는 것
  나. 학습 데이터를 절반으로 줄이는 것
  다. 배치 사이즈를 1로 고정하는 것
  라. 학습률을 0으로 만드는 것

14. SFTTrainer 학습에서 과적합을 의심할 수 있는 신호는?
  가. train loss와 eval loss가 함께 감소한다
  나. train loss는 감소하는데 eval loss가 증가한다
  다. 학습률이 일정하게 유지된다
  라. 에포크가 1보다 작다

15. DPO에서 필요한 데이터 형태는?
  가. 질문 하나에 대한 chosen 답변과 rejected 답변의 쌍
  나. 정답만 있는 단답형 데이터
  다. 이미지와 캡션의 쌍
  라. 번역 원문과 번역문의 쌍

16. 파인튜닝 후 추론 배포 시 어댑터 병합(merge)의 장점은?
  가. 추론 시 추가 연산 없이 단일 모델로 서빙할 수 있다
  나. 학습 시간을 단축시킨다
  다. 데이터가 필요 없어진다
  라. 양자화가 자동으로 된다

17. 지식이 매주 바뀌는 서비스에 가장 적합한 접근법은?
  가. 매주 파인튜닝을 다시 돌린다
  나. RAG로 문서를 교체해 반영한다
  다. 프롬프트에 모든 문서를 매번 붙여넣는다
  라. 모델을 처음부터 다시 학습시킨다

18. 답변의 출처 근거를 사용자에게 보여줘야 하는 요구사항이 있을 때 유리한 기술은?
  가. 파인튜닝
  나. RAG
  다. 프롬프트 엔지니어링만
  라. 양자화

19. 사내 챗봇에서 지식은 자주 바뀌지만 응대 말투는 고정되어 있을 때 합리적인 설계는?
  가. 지식은 RAG로, 말투와 형식은 파인튜닝으로 분담한다
  나. 모든 것을 파인튜닝 하나로 해결한다
  다. 모든 것을 RAG 하나로 해결한다
  라. 챗봇을 만들지 않는다

20. (단답형) 검색 품질을 평가할 때 정답 문서가 상위 k개 안에 들어오는 비율을 나타내는 지표의 이름은?

### 해설

1. 정답: 가. LLM은 학습이 끝난 시점 이후의 지식이나 학습 데이터에 없는 정보를 물을 때 그럴듯한 내용을 지어낸다. 이를 지식 마감(knowledge cutoff)과 환각이라 하며, RAG는 관련 문서를 함께 제공해 이 문제를 완화한다. 나, 다, 라는 원인이 아니다.

2. 정답: 나. 코사인 유사도는 두 벡터가 가리키는 방향의 유사도를 재며, 1에 가까울수록 같은 방향, 즉 의미적으로 가깝다는 뜻이다. 0은 무관계, -1은 반대 방향이다.

3. 정답: 나. 임베딩 모델마다 만드는 벡터 공간이 다르므로, 인덱싱과 질의에 다른 모델을 쓰면 유사도 계산이 의미를 잃는다. 같은 모델로 인덱싱과 질의를 처리하는 것이 원칙이다.

4. 정답: 나. 수백만 건 이상의 벡터에서 정확한 최근접 이웃을 찾는 것은 계산 비용이 너무 크다. ANN은 약간의 정확도를 포기하는 대신 검색 속도를 크게 확보한다.

5. 정답: 나. 400~512 토큰은 문맥을 충분히 담으면서도 검색 정밀도를 유지하기 좋은 크기다. 문장 경계에서 자르고 10~20퍼센트 오버랩을 두면 경계에서 잘리는 정보를 보완할 수 있다.

6. 정답: 가. RRF는 벡터 검색과 BM25 검색처럼 서로 다른 두 검색기의 순위 목록을 하나의 순위로 융합하는 방법이다. 각 문서의 순위에 역수를 취해 합산하므로 두 검색기의 점수 척도가 달라도 합칠 수 있다.

7. 정답: 나. 리랭킹은 크로스엔코더 추론 비용이 추가되므로, 정밀도가 실제 병목인지 측정으로 확인한 뒤에 도입해야 한다. 측정 없이 붙이면 비용만 늘고 효과는 없을 수 있다.

8. 정답: 가. faithfulness(충실도)는 생성된 답변이 검색된 문맥에 근거하고 있는지를 측정한다. 문맥에 없는 내용을 답이 지어내고 있지 않은지를 보는 지표다.

9. 정답: 나. 에이전틱 RAG에서는 에이전트가 질문을 보고 검색이 필요한지 판단하고, 필요하면 검색 도구를 호출한 뒤 결과를 보고 다시 추론하는 루프를 돈다.

10. 정답: 라. 파인튜닝은 최후의 수단이다. 프롬프트 개선, RAG, 퓨샷 예제로 해결되지 않을 때 검토한다. 바로 학습을 시작하면 비용과 시간을 낭비하기 쉽다.

11. 정답: 가. 저품질 데이터로 학습하면 모델이 잘못된 말투, 형식, 사실을 그대로 익힌다. 수천 건의 좋은 데이터가 수만 건의 나쁜 데이터보다 낫다.

12. 정답: 나. LoRA는 원래 가중치 W0를 고정하고 저랭크 행렬 A와 B만 학습한다. W = W0 + BA 형태로, 학습 파라미터 수가 원래 가중치에 비해 매우 적다.

13. 정답: 가. QLoRA는 NF4 4비트 양자화로 가중치를 메모리에 올리는 부담을 줄이고, 역전파는 저랭크 어댑터에만 적용해 16GB GPU 한 장으로도 큰 모델 학습이 가능하게 한다.

14. 정답: 나. train loss는 계속 줄지만 eval loss가 올라가기 시작하면 모델이 학습 데이터를 외우기 시작했다는 신호다. 이때는 학습을 중단하거나 정규화, 데이터 증강을 검토한다.

15. 정답: 가. DPO는 같은 질문에 대한 선호 답변(chosen)과 비선호 답변(rejected)의 쌍으로 학습한다. 보상 모델을 따로 학습하지 않고 선호도 데이터에서 직접 최적화하는 것이 특징이다.

16. 정답: 나. 어댑터를 베이스 모델에 병합하면 추론 시 어댑터 연산이 따로 필요 없어 단일 모델처럼 서빙할 수 있다. 다만 병합하면 어댑터 교체가 어려워지므로, 여러 어댑터를 바꿔가며 쓸 때는 분리 서빙을 선택한다.

17. 정답: 나. 지식이 매주 바뀌면 파인튜닝을 매번 다시 돌리는 것은 비용이 너무 크다. RAG는 문서만 교체하면 즉시 반영되므로 이런 경우에 적합하다.

18. 정답: 나. RAG는 검색한 문서를 그대로 보여줄 수 있어 출처 근거 제시에 유리하다. 파인튜닝은 지식이 가중치 속에 있어 출처를 특정하기 어렵다.

19. 정답: 가. 자주 바뀌는 지식은 RAG가, 잘 바뀌지 않는 말투와 형식은 파인튜닝이 담당하는 분업이 유지 비용과 품질 면에서 합리적이다. 40장에서 다룬 함께 쓰는 패턴이다.

20. 정답: recall@k. 정답 문서 집합 중 상위 k개 검색 결과에 포함된 비율로, 검색 단계의 품질을 측정하는 기본 지표다. 검색과 생성을 분리해 측정할 때 검색 쪽 지표로 쓴다.

### 핵심 정리

- 20문항은 책의 전체 흐름을 따라간다: RAG 기초(1~9번), 파인튜닝(10~16번), 선택과 실전(17~20번).
- 틀린 문항이 몰린 파트를 다시 읽는 것이 가장 빠른 복습 방법이다.
- 해설의 키워드(지식 마감, ANN, RRF, faithfulness, LoRA, DPO, recall@k)가 바로 이 책의 핵심 용어다.
